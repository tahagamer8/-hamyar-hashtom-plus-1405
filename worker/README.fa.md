# راه‌اندازی API دستیار فهمینو

این پوشه یک سرور واسط Cloudflare Worker برای اتصال امن اپ به Gemini است. کلید Gemini فقط باید در بخش Secretهای Worker نگهداری شود و هرگز در Flutter، APK، فایل‌های Git یا GitHub قرار نگیرد.

## پیش‌نیاز و نکتهٔ سنی
راه‌اندازی حساب‌های سرویس ابری و هرگونه فعال‌سازی پرداخت یا صورتحساب باید با کمک و نظارت والد/سرپرست انجام شود. پیش از فعال‌سازی، هزینه و سهمیهٔ حساب را بررسی کنید؛ رایگان بودن یا مقدار سهمیه تضمین‌شده نیست.

## استقرار روی Worker موجود
1. از Worker موجود با نام دقیق `fahmino-api-2` استفاده کنید؛ Worker قدیمی `fahmino-api` را تغییر ندهید.
2. محتوای `worker/src/index.js` را در Worker با نام `fahmino-api-2` قرار دهید.
3. در Settings → Variables and Secrets یک Secret با نام دقیق `GEMINI_API_KEY` ایجاد کنید. مقدار کلید را در کد، GitHub، APK یا گفت‌وگو قرار ندهید.
4. در بخش Bindings یک Rate Limiting binding با نام دقیق `CHAT_LIMITER` بسازید؛ محدودیت پیشنهادی ۲۰ درخواست در ۶۰ ثانیه برای هر IP است. بدون این binding، Worker عمداً درخواست‌های چت را با خطای پیکربندی رد می‌کند.
5. اگر از تنظیمات `worker/wrangler.toml` استفاده می‌کنید، پیش از انتشار مطمئن شوید شناسهٔ `namespace_id` برای حساب شما یکتا است.
6. Worker را Deploy کنید. آدرس پایهٔ آن در فهمینو از قبل تنظیم شده است:
   `https://fahmino-api-2.tahamrh2.workers.dev`
7. مسیر API به‌صورت خودکار `/api/chat` است.

## محدودیت‌های نسخهٔ آزمایشی
- حداکثر ۱۲ پیام در هر درخواست و ۳۰۰۰ نویسه برای هر پیام
- خروجی حداکثر ۹۰۰ توکن
- خطاهای سرویس به پیام فارسی تبدیل می‌شوند
- محدودسازی Cloudflare بر اساس IP و به‌صورت تقریبی و جداگانه در هر موقعیت Cloudflare است؛ کاربران پشت یک شبکه ممکن است سهمیهٔ مشترک داشته باشند و درخواست‌ها ممکن است از حد عبور کنند. این محدودیت سقف قطعی جهانی یا جایگزین احراز هویت نیست. برای انتشار عمومی، احراز هویت و سهمیهٔ مجزای کاربر اضافه کنید.
- CORS برای تست باز است؛ CORS به‌تنهایی کنترل دسترسی نیست.

## قرارداد API
`POST /api/chat`

```json
{
  "messages": [
    { "role": "user", "text": "عدد گویا چیست؟" }
  ],
  "studyContext": {
    "subjectTitle": "ریاضی",
    "chapterTitle": "عددهای صحیح و گویا",
    "summary": "خلاصهٔ آموزشی انتخاب‌شده از فهمینو",
    "sourceLabel": "محتوای اولیه؛ هنوز تطبیق نهایی نشده"
  }
}
```


`studyContext` اختیاری است. Worker فقط فیلدهای آموزشی مجاز را می‌پذیرد، طول متن را محدود می‌کند و آن را به‌عنوان دادهٔ مرجعِ غیرقابل‌اعتماد به مدل می‌دهد؛ بنابراین متن فصل جایگزین کتاب رسمی نیست و نباید حاوی اطلاعات شخصی باشد.

پاسخ موفق:

```json
{ "answer": "..." }
```
