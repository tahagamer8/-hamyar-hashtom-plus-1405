# راه‌اندازی API دستیار فهمینو

این پوشه یک سرور واسط Cloudflare Worker برای اتصال امن اپ به Gemini است. کلید Gemini فقط باید در بخش Secretهای Worker نگهداری شود و هرگز در Flutter، APK، فایل‌های Git یا GitHub قرار نگیرد.

## پیش‌نیاز و نکتهٔ سنی
راه‌اندازی حساب‌های سرویس ابری و هرگونه فعال‌سازی پرداخت یا صورتحساب باید با کمک و نظارت والد/سرپرست انجام شود. برای آزمایش اولیه، هزینه و سهمیهٔ حساب را قبل از فعال‌سازی بررسی کنید؛ رایگان بودن یا مقدار سهمیه تضمین‌شده نیست.

## مراحل استقرار
1. یک Worker جدید با نام `fahmino-gemini-api` بسازید. مدل پیش‌فرض پروژه `gemini-3.8-flash` است؛ مدل‌های جدید و پایدار را از مستندات رسمی بررسی کنید.
2. محتوای فایل `src/index.js` را در ورودی Worker قرار دهید.
3. در تنظیمات Worker، یک Secret با نام دقیق `GEMINI_API_KEY` اضافه کنید. مقدار کلید را در کد یا این مخزن قرار ندهید.
4. Worker را منتشر کنید.
5. آدرس عمومی Worker را در صفحهٔ «دستیار هوشمند» فهمینو وارد کنید. مسیر API به‌صورت خودکار `/api/chat` است.\n6. مقدار `namespace_id` در `wrangler.toml` باید در حساب Cloudflare شما یکتا باشد؛ اگر قبلاً استفاده شده، یک عدد مثبت دیگر انتخاب کنید. محدودکنندهٔ فعلی حدود ۲۰ درخواست در هر ۶۰ ثانیه به‌ازای IP اعمال می‌کند.

## محدودیت‌های نسخهٔ آزمایشی
- حداکثر ۱۲ پیام در هر درخواست و ۳۰۰۰ نویسه برای هر پیام
- خروجی حداکثر ۹۰۰ توکن
- خطاهای سرویس به پیام فارسی تبدیل می‌شوند
- محدودسازی Cloudflare بر اساس IP و به‌صورت تقریبی است؛ کاربران پشت یک شبکه ممکن است سهمیهٔ مشترک داشته باشند و محدودیت، سقف قطعی جهانی نیست. برای انتشار عمومی، احراز هویت و سهمیهٔ مجزای کاربر اضافه کنید.
- CORS برای تست باز است؛ برای انتشار عمومی، دامنهٔ اپ/وب خود را محدود کنید.
