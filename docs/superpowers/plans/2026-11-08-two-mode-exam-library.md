# برنامهٔ اجرا — دو مسیر نمونه‌سؤال و آزمون‌های نوبتی

## محدودیت‌های سراسری
- شاخه: `audit/textbook-alignment-1405`
- مبنا: نسخهٔ موجود فهمینو در همین شاخه.
- سؤال‌های تازه تألیفی‌اند؛ متن یا بانک رقیب کپی نمی‌شود.
- تمام داده‌ها باید زیر `assets/` باشند تا بدون اینترنت در APK کار کنند.
- UI فارسی و RTL و سازگار با طراحی فعلی حفظ شود.

## کارها
1. **تست پذیرش UI را اضافه کن.** تست کند دو مسیر فصل‌به‌فصل و نوبت اول/دوم در نمونه‌سؤال نمایش داده می‌شوند؛ ابتدا باید شکست بخورد.
2. **دادهٔ نمونه‌سؤال را توسعه بده.** برای تمام ۱۴۵ فصل/بخش در ۱۳ بسته، سؤال‌های استدلالی تألیفیِ دارای گزینه، کلید و توضیح اضافه کن؛ سؤال‌های فعلی حفظ شوند.
3. **صفحهٔ نمونه‌سؤال را بساز.** دو مسیر اصلی، انتخاب فصل، انتخاب نوبت، کارت سؤال و نمایش پاسخ را پیاده کن.
4. **آزمون نوبتی را متصل کن.** از بانک آفلاین همان درس سؤال‌های نوبت را انتخاب کن؛ عنوان و تاریخچهٔ آزمون برای نوبت اول و دوم جدا باشد.
5. **PDFها را هم‌راستا کن.** اسکریپت تولید PDF سؤال‌های پیشرفته/نوبتی را نیز وارد جزوه و مجموعه نمونه‌سؤال کند.
6. **تست داده و رابط را کامل کن.** ۱۳ درس، ۱۴۵ بخش، هر دو نوبت، پاسخ معتبر، تعداد سؤال، فیلتر فصل و تاریخچه بررسی شوند.
7. **ساخت انتشار را اجرا کن.** تحلیل Dart، کل تست‌ها، تولید PDF، سه APK را اجرا کن؛ artifact نهایی دانلود و محتویات بسته بررسی شود.
8. **مقایسهٔ رقبا را به‌روزرسانی کن.** مزیت‌ها و شکاف‌ها در برابر همیار، پادرس و گاما با لینک منابع درج شود.

## تعریف پایان
کار فقط وقتی قابل انتشار گزارش می‌شود که آخرین run برای آخرین commit موفق باشد، artifacts هر سه APK حاضر باشند، محتویات APK نشان دهد JSONها و PDFها بسته‌بندی شده‌اند و تست‌ها سبز باشند. تست روی گوشی واقعی به‌عنوان نیازمند نصب انسانی جدا ثبت شود.
