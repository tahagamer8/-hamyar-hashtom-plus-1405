# Source ledger and permitted use

| Source | Role | Use permitted in Fahmino | Prohibited without permission |
|---|---|---|---|
| https://chap.sch.ir/ | Official grade-eight textbook/curriculum reference | Verify subject, chapter, terminology and learning objectives; link to official books | Repackage or reproduce protected book content beyond applicable permissions |
| https://hamyar.me/ | Comparative learning platform | Inspect chapter coverage, navigation, question categories and PDF UX; link to their own resource pages | Copy text, questions, worked solutions, PDFs, images or distinctive arrangement |
| https://paadars.com/ | Comparative learning platform | Inspect explanation depth, practice progression, organization and PDF UX; link to their own resource pages | Copy text, questions, worked solutions, PDFs, images or distinctive arrangement |
| Official Samad/SAMPAD publications and notices | Enrichment learning objectives and public educational guidance | Use publicly stated skill domains and high-level objectives; independently author new problems | Copy test questions, books, worksheets, diagrams, answer keys or PDFs unless an explicit reuse license/permission allows it |

No official Samad resource with a clearly documented redistribution license was verified during this update. Therefore this release uses the official textbook portal as the curriculum anchor and treats Samad-style enrichment as an original question-design standard, not copied source content.
